# Reaction Roll

In most instances, NPCs’ reactions will be obvious based on the circumstance of the encounter. If there is any doubt, roll 2d6 and consult the following chart. This chart can also be used in any situation where someone is attempting to convince an NPC as to a course of action and there is doubt as to the outcome.

| 2d6 Roll | Reaction    |
| -------- | ----------- |
| 2    | Hostile     |
| 3-5  | Unfriendly  |
| 6-8  | Indifferent |
| 9-11 | Talkative   |
| 12   | Helpful     |

!!! note "Modifiers"
    Modifiers may apply to the roll depending on the character, the situation, or both — a Peasant's rapport with animals, a Townsman on home ground, a Leadership bonus, a well-judged gift or a drawn blade. The Referee decides what a given circumstance is worth.
