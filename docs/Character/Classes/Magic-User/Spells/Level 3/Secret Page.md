# Secret Page

**Class**: Magic-User  
**Level**: 3  
**Duration**: Permanent  
**Range**: Touch  

This spell allows the caster to disguise a single page in a book (or inscriptions on a tombstone, a framed painting, or any sort of medium analogous to a “page”) as something else.

The caster will still see the information as it truly is, but all others looking upon it will see the illusory information as determined by the caster.
