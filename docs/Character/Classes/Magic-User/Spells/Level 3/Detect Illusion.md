# Detect Illusion

**Class**: Magic-User  
**Level**: 3  
**Duration**: 3 Rounds + 2 Rounds/level  
**Range**: 0  

The caster places this enchantment on himself to grant sight that sees through illusion. Illusions can be seen in an area 10' wide and 10' long per level. The caster can touch one other creature, granting it the ability to see through illusion as well, so long as the contact is maintained.
