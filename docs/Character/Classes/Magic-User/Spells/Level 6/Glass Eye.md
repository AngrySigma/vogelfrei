# Glass Eye

**Class**: Magic-User  
**Level**: 6  
**Duration**: 1 Round/level  
**Range**: Touch  

The caster of this spell is able to see through walls as if a 3' square window is present. For the duration of the spell, the caster can see through more than just one wall, but it takes one Round to switch from one wall to another. The arcane window, according to the caster’s preference, can be made visible to other creatures. However, if it is made visible to others it can only be applied to one wall. The window is always one way. The spell can be applied to 20' thick wood, 6' thick stone, or 4" thick metal. Platinum, gold, and lead block this spell.
