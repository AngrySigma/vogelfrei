# Maze

**Class**: Magic-User  
**Level**: 8  
**Duration**: See Below  
**Range**: 5'/level  

The caster banishes the subject into an extra dimensional labyrinth. The number of Turns or Rounds the subject takes to escape this labyrinth is determined by his Intelligence.

Referees should estimate the targeted Intelligence of the monster or NPC (if it has no given stats).

| Intelligence | Time in Labyrinth |
|--------------|-------------------|
| 3 or less    | 3d4 Turns         |
| 4–5          | 2d4 Turns         |
| 6–8          | 1d4 Turns         |
| 9–12         | 4d4 Rounds        |
| 13–15        | 3d4 Rounds        |
| 16–17        | 2d4 Rounds        |
| 18+          | 1d4 Rounds        |
