# Detect Invisible

**Class**: Magic-User  
**Level**: 2  
**Duration**: 5 Rounds/level  
**Range**: 10'/level  

By means of this spell the caster is able to see invisible characters, creatures, or objects within the given range, seeing them as translucent shapes.
