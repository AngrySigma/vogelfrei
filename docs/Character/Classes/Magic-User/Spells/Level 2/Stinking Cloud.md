# Stinking Cloud

**Duration**: 1 Round/level  
**Range**: 30'  

Stinking Cloud creates a 20' cubed bank of fog centered anywhere within range, making living creatures within it helpless with nausea. This condition lasts as long as a creature is in the cloud and for 1d4+1 Rounds after it leaves. Any creature that succeeds in a saving throw versus Poison when leaving the fog is not affected for the additional Rounds.
