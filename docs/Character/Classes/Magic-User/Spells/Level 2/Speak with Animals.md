# Speak with Animals

**Duration**: 2 Rounds/level  
**Range**: 0  

The caster can comprehend and communicate with ordinary animals or giant versions of ordinary animals. The caster can ask questions of, and receive answers from, one particular kind of animal, although the spell does not make it any more friendly or cooperative than normal. The type of animal is decided when the spell is cast. If an animal is friendly toward the caster, it may do him some favor or service.
