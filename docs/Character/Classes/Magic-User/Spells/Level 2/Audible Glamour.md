# Audible Glamour

**Class**: Magic-User  
**Level**: 2  
**Duration**: 1 Round/level  
**Range**: 60' + 10'/level  

The caster of this spell is able to create false sound. The sound can be centred anywhere within range, and within that range the sound can fluctuate and move, imitating approaching or receding footsteps, laughter, voices, or whatever else the caster desires. Beings are allowed a saving throw versus Magic to realize that the effect is illusory, but only if they actively attempt to disbelieve.
