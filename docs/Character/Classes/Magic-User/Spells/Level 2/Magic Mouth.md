# Magic Mouth

**Duration**: Permanent  
**Range**: See Below  

This enchantment is set upon an object, and the magic is triggered when certain conditions established by the caster are met. When that happens, a mouth appears in the object and speaks the message it has been commanded to speak. The message can be up to 30 words long.
