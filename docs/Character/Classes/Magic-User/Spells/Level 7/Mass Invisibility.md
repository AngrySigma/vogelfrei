# Mass Invisibility

**Class**: Magic-User  
**Level**: 7  
**Duration**: 1 Turn/level  
**Range**: 10'/level  

This spell is identical to the [Invisibility 10' Radius](../Level%203/Invisibility%2010'%20Radius.md) spell, but all living things (and their equipment) in a 30' square area become invisible. After the spell is cast, those affected do not have to remain within this area; it is as if individual [Invisibility](../Level%202/Invisibility.md) spells have been cast on each of them.
