# Reverse Gravity

**Class**: Magic-User  
**Level**: 7  
**Duration**: 1 Round  
**Range**: 5'/level  

Nature is a Magic-User’s plaything, and this spell commands the earth to throw away people and objects standing upon it. This affects a 30' square area, causing all unattached objects and creatures within that area to “fall” upward 20'. If some solid object (such as a ceiling) is encountered in this fall, falling objects and creatures strike it in the same manner as they would during a normal downward fall. If an object or creature reaches the maximum height without striking anything, it remains there, oscillating slightly, until the spell ends. At the end of the spell duration, affected objects and creatures fall downward, suffering the usual falling damage when they hit the ground.
