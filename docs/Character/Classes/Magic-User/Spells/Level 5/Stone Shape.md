# Stone Shape

**Class**: Magic-User  
**Level**: 5  
**Duration**: Instantaneous  
**Range**: Touch  

This spell can form an existing piece of stone into any shape that suits the caster’s purpose, to a total volume of 1' cubed per level. While it is possible to make crude coffers, doors, and so forth with stone shape, fine detail is not possible.
