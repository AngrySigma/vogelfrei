# Wizard Eye

**Class**: Magic-User  
**Level**: 4  
**Duration**: 1 Turn/level  
**Range**: 0  

The caster creates an invisible magical sensor that sends visual information, and can see with 60' darkvision. The eye travels up to 120' each Turn. The eye can travel in any direction as long as the spell lasts. Solid barriers block its passage, but it can pass through a hole or space as small as 1 inch in diameter.
