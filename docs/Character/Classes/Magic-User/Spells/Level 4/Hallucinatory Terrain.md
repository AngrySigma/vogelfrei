# Hallucinatory Terrain

**Class**: Magic-User  
**Level**: 4  
**Duration**: Permanent  
**Range**: 240'  

The caster makes some terrain look, sound, and smell like another sort of terrain, but the entire terrain to be hidden must be encompassed by the range that this spell can affect. The caster can affect a 10' square area per caster level.
