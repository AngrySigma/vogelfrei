# Extension

**Class**: Magic-User  
**Level**: 4  
**Duration**: See Below  
**Range**: 0  

This spell reminds magic forces that they are not bound by natural time and so lengthens the duration of another spell previously cast by the Magic-User by 50%. The previous spell must still be active.
