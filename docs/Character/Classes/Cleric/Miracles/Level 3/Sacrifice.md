# Sacrifice

**Class**: Cleric  
**Level**: 3  
**Duration**: Instantaneous  
**Range**: Touch  

This spell allows the Cleric to transfer any desired number of Wounds from himself to the target. The reverse of this spell, **Drain Life**, allows the caster to drain 1d6+1 Wounds from a creature, with a successful attack roll. The Wounds are transferred to the cleric through healing.
