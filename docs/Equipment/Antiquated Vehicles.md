# Antiquated Vehicles

These entries are retained for ruins, legendary voyages, archaic regions, and campaigns that deliberately reach outside the age. They are not ordinary vehicles for sale in the core setting.

| Vehicle | Cost |  | Period note |
| --- | ---: | ---: | --- |
|  | City | Rural |  |
| Chariot | 250sp | - | Ancient prestige and war vehicle |
| Trireme | 10000sp | - | Oared warship of classical antiquity |

## Later Names and Designs

| Vehicle | Cost | Period note |
| --- | ---: | --- |
| Brig | 90000sp | The familiar two-masted brig belongs to later naval usage; use a Brigantine in the core period |
| Corvette | 135000sp | The standardized corvette category belongs to later naval usage; use a Sloop or small Frigate |

The Referee may use these costs as-is when such a vessel appears. Crew, armament, cargo, and provisions remain separate, as on the main [Vehicles](Vehicles.md) page.
