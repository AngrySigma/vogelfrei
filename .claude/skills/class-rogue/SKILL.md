# Rogue class kit

Finishes a Rogue after the core `character-generation` workflow. Works on the
same character JSON (`--file`); `$S` =
`.claude/skills/character-generation/scripts`.

Stop if the JSON's `class` is not `Rogue`.

Read `docs/Character/Classes/Rogue/index.md` and `docs/Adventuring/Skills.md`
(what each skill does and how it is rolled).

## 1. What the Rogue class gives

**The Rogue has no careers.** It is a class in itself — everything with real
mechanics sits on the class page.

From the class page: Wounds `1d6 (min 4)`, Stamina `1d3`, its own saving-throw
row (all set by `apply_class.py`), **WS +0 / BS +0**, a nine-skill list, the
**Sneak Attack** trait, and **2 Skill Points** at level 1 (+2 per level after).
The class has no forced alignment and its flavour is the adaptable outsider —
"a Rogue may have been anything before taking to the road."

Starting possessions and Status are not yet written on the class page; see §3.

## 2. Skills and the Skill-Point spend

**Base proficiency.** Every character already has a 1-in-6 chance in each of
the Rogue's skills (Architecture, Bushcraft, Climb, Doors, Languages, Search,
Sleight of Hand, Stealth, Tinkering). Skill Points raise them: one point =
+1-in-6 to one skill.

**Spend the 2 points.** Two ways, agent's judgement:

- **Given a brief** — if the request named a skill set or described the
  character ("a cat burglar", "a con artist", "a tomb robber"), assign the 2
  points to fit it. A burglar leans Stealth/Climb/Doors; a pickpocket Sleight
  of Hand/Stealth; a tomb robber Search/Tinkering/Architecture.
- **No brief** — roll a weighted spread, the street-skills weighted high and
  the scholarly ones ("lore of magic" types) low, per the player's steer:

```
python3 - <<'PY'
import random
weights = {"Stealth":5, "Sleight of Hand":4, "Search":4, "Climb":3,
           "Doors":3, "Tinkering":3, "Bushcraft":2, "Architecture":1,
           "Languages":1}
POINTS, CAP = 2, 2          # 2 points at L1; both may pile on one skill (-> 3-in-6)
adv, skills, w = {}, list(weights), list(weights.values())
while sum(adv.values()) < POINTS:
    s = random.choices(skills, weights=w)[0]
    if adv.get(s, 0) < CAP:
        adv[s] = adv.get(s, 0) + 1
for s in sorted(adv):
    print(f"{s}={1 + adv[s]}")     # final N-in-6 = base 1 + advances
PY
```

Record the improved skills at their final rating (the untouched ones stay at
the universal 1-in-6, no need to list them):

```
python3 $S/annotate.py --file ... --skill "Stealth=2" --skill "Sleight of Hand=2"
python3 $S/annotate.py --file ... --note "Base 1-in-6 in all other Rogue skills; +2 Skill Points per level after 1st"
```

**Sneak Attack.** Note its trigger so it is not forgotten in play: an attack on
an unaware or Surprised target (classically straight out of Stealth) rolls the
weapon's damage dice twice and adds both. The Rogue is also the trained
specialist the skill rules allow for, and ignores the Climb-while-encumbered
restriction — worth a note if they are carrying much:

```
python3 $S/annotate.py --file ... --note "Sneak Attack: double damage dice vs unaware/Surprised targets. May Climb while encumbered."
```

## 3. Status is a judgement call

The class page defines no Status yet, so `apply_class.py` will have stopped for
`--status`. A Rogue has "no official social standing," so **Brass** is the
honest default (Silver for one with some means). Note that you supplied it:

```
python3 $S/annotate.py --file ... \
    --note "Status set to <Brass|Silver> by judgement — the Rogue class page defines none yet"
```

## 4. Weapons

There is no Trained/Untrained weapon system. Any character may pick up and use
any weapon, except those marked with an asterisk in the melee table and **every
ranged weapon and firearm** — those take real instruction, and the Referee
decides what a character's background already covers. A Rogue's background
plausibly covers a sling, a bow or a dagger; a rapier or a wheellock is a
harder sell. A Rogue's edge is the Sneak Attack, not the weapon list.

## 5. Re-render

```
python3 $S/finalize.py --file ...        # only if equipment changed
python3 $S/render_sheet.py --file ... --out characters/<slug>.md
```

Skills, Sneak Attack and any notes render on the sheet. Present the Rogue in a
line: a specialist who lives by nine skills and a doubling Sneak Attack from
the shadows — light on armour and weapons, heavy on guile.
