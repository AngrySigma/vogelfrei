# House style — apply silently

Wording only. **None of this is an inconsistency and none of it is
reported.** Where the docs are split, the majority spelling wins; the counts
are recorded so the rule can be re-derived if usage shifts.

For mechanical divergences — damage, healing, AC, Stamina — see
`mechanics.md`. Those *are* reported.

## Source → Vogelfrei

| Source | Use | Note |
|---|---|---|
| Cleric spell | **Miracle** | directory, index title and prose |
| Fighter | **Warrior** | |
| Specialist | **Rogue** | |
| Elf | **High Elf** / **Wood Elf** | two classes — ask only if the effect depends on which |
| Lawful / Law | **Orderly** / **Order** | |
| Evil (alignment sense) | **Chaos** / **Chaotic** | `Detect Evil` → `Detect Chaos`, `Protection from Evil` → `Protection from Chaos` |
| `&` in a spell name | **and** | `Purify Food & Drink` → `Purify Food and Drink` |

Unchanged: `Referee`, `Magic-User`, `Hit Dice`, silver-standard `sp`,
`saving throw versus <category>`, Turn/Round/Turn units.

`Armor Class` stays the name of the composed to-hit target — it is not a
synonym for `Armor Rating`, which is the armour's own contribution.

## Alignment

**Order · Neutrality · Chaos** (`docs/Character/Alignment.md`). No Good/Evil
axis. Clerics must be Orderly; Magic-Users and Elves must be Chaotic.

A spell keyed to the *caster's* alignment can collide with those forced
alignments — that is mechanical, so report it.

## Saving throws

Five categories: **Paralyze · Poison · Breath · Device · Magic**.
Write `saving throw versus Magic` (19 uses) over `save versus Magic` (3).
